# 5교시 시작 안내

1. `AN-Harness-Lesson05-Context.zip` 전체를 다운로드합니다.
2. Windows 파일 탐색기에서 ZIP의 압축을 `C:\AI-Native`에 풉니다.
3. `C:\AI-Native\harness-engineering\lesson05.ps1`이 `compose.yaml`과 나란히 있는지 확인합니다.
4. `05_context_engineering_preview.html` 또는 `05_context_engineering.md`의 단계 1부터 진행합니다. 압축 해제·파일 확인·준비 명령의 역할을 순서대로 안내합니다.

패키지에는 가이드북, 실행 스크립트, Context 문서, 검토 요청, 관찰 기록 양식과 전체 작성 예시가 있습니다. 공통 CSV는 3교시부터 사용한 원본을 그대로 사용합니다.

정상 진행은 `prepare`로 시작합니다. 복원은 문제가 생겼을 때 가이드북 7)의 절차를 사용합니다.
