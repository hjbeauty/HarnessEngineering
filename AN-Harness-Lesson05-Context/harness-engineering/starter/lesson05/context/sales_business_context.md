# 판매 데이터의 업무 배경

사무·IT 주변기기를 판매하는 가상 기업의 교육용 합성 주문 기록입니다. 실제 고객 정보나 실제 매출 기록이 아닙니다. 데이터의 날짜는 시나리오 날짜이며 수업 당일을 기준으로 미래 주문을 제거하지 않습니다.

담당자는 판매 현황을 파악하려고 합니다. 제품별 판매 수량과 매출은 서로 다른 지표입니다. 단가가 높은 제품은 수량이 적어도 매출이 높을 수 있습니다. 비용·이익·재고·고객 수 데이터는 없으므로 이를 계산하거나 증감의 원인을 사실로 단정하지 않습니다.

| 열 | 의미 |
|---|---|
| date | 주문일. 분석 기간은 입력에 실제로 있는 날짜를 확인 |
| order_id | 한 행을 식별하는 주문 ID. 이 교육 데이터에서는 한 주문에 한 제품을 기록 |
| category / product | 제품 분류와 제품명 |
| quantity | 해당 주문의 판매 수량 |
| unit_price | 그 주문에 실제 적용된 원 단위 단가. 할인은 이미 반영 |
| region | 주문 지역 |

행 매출은 수량 × 실제 적용 단가입니다. 할인율을 다시 적용하지 않습니다. 모든 금액은 원 단위이며 세금·환율·반품 조정은 이 데이터에 포함하지 않습니다.

같은 제품이라도 주문에 따라 단가가 다릅니다. 최초 200행 데이터의 추가 생성 행에는 기준가에 할인율을 적용한 후 천 원 단위로 반올림한 값이 있습니다. 제공된 실제 단가를 그대로 사용합니다. 후속 시험 파일에는 소액·큰 금액도 있으며 가격 차이만으로 잘못된 입력이라고 판단하지 않습니다.
