# 반드시 지킬 경계

출처: 과정의 실행 통제 규칙. 확인: 5교시 문서 검토 시작 전.

- 입력 원본 /inputs/lesson03/sales.csv를 수정하지 않습니다.
- 보고서를 생성하는 단계에서는 /workspace/outputs/에 저장합니다.
- 5교시 검토 요청에서는 문서 읽기만 허용합니다. 파일 생성·수정·삭제와 코드 구현을 하지 않습니다.
- 모델, 추론 설정, 승인 설정, Memory와 Skill 상태를 변경하지 않습니다.
- API Key와 로그인 비밀번호를 읽거나 문서에 기록하지 않습니다.
- 이번 분석을 위해 외부 검색이나 추가 데이터 다운로드를 하지 않습니다.
- 충돌하는 지시는 근거와 함께 보고하고, 사람이 정리하기 전에는 실행하지 않습니다.
